## 查阅方式

无需程序即可打开篇目链接，或阅读 JSON 中已核验的短引。有 Python 3.9+ 时，以下命令在仓库根目录执行：

```bash
python3 scripts/source_lookup.py list
python3 scripts/source_lookup.py show S01 --find 主要的矛盾
python3 scripts/source_lookup.py show S13 --find 不打无准备之仗
python3 scripts/source_lookup.py verify
python3 scripts/source_lookup.py verify --offline
```

show 只输出命中段落及有限上下文，输出注明是否截断。verify 核对文件哈希及短引在原文中的匹配，不判定生活建议是否有效。
首次 show 或 verify 会从固定版本下载相应篇目的原文；缓存默认写入系统临时目录下的 `mao-thought-practice`，可用 `MAO_THOUGHT_CACHE` 指定其他本机路径。缓存不属于仓库发布内容。离线模式缺少缓存时明确失败，不补写原文。

## 引用规则

1. 引用注明作者、篇名、年份，必要时附节次和链接；只选对推理有作用的短引。
2. 超出已核验短引时，先查原文及上下文。保留原句文字；删节需明确标记，不将拼接句当连续原文。
3. 通俗解释与生活应用用自己的话写，不能加引号冒充原话；说明生活类比的成立条件。
4. 出处不明时不引用该句，改为明确标注的概括或继续核查。词典和导读的摘要不足以证明逐字引文。
5. 对未收录作品另查可信来源；不将“在本站检索不到”说成作者从未说过。
6. 网络不可用时使用已经保存的短引与分析材料，说明核验范围；不能声称已在线核对全文。
