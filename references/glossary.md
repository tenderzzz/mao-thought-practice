# 概念词典：24 个概念与常见混淆

以下均为通俗释义，不作逐字引文。S 编号查 [原文索引](sources.md)。解释概念时按需补原语境和例子；名句的逐字核验使用来源记录与正文。

| 概念 | 核心意思 | 使用时要区分 | 来源 |
|---|---|---|---|
| 1. 实事求是 | 从实际材料中研究内部联系和规律，用于指导行动 | 愿望、印象、已有证据和推断 | S08 |
| 2. 矛盾／对立统一 | 同一过程中的双方既相互依存又相互制约 | 不是任意两项利弊，也不等于人与人争吵 | S01 |
| 3. 主要矛盾 | 给定过程、阶段中规定或影响其他矛盾的一组关系 | 紧急任务、最强情绪、行动重点 | S01 第四节 |
| 4. 矛盾的主要方面 | 同一矛盾内部占主导的方面，事物性质主要受它规定 | 不是另一条“最重要的矛盾” | S01 第四节 |
| 5. 矛盾的特殊性 | 不同对象、过程、阶段及矛盾双方各有特点 | 通用经验需要结合具体条件重查 | S01 第三节 |
| 6. 内因与外因 | 内部矛盾是发展的根据，外部条件通过内部结构发生作用 | 分析对象的内外不等于个人可控与不可控 | S01 第一节 |
| 7. 两点论与重点论 | 兼顾相关方面，同时分清主次 | 是后来的概括，不标作毛泽东原话；不要求机械五五分 | S01 |
| 8. 实践与认识／两次飞跃 | 材料经分析形成认识，再指导实践并检验修正 | 做过不等于理解了，理解了不等于已验证 | S02 |
| 9. 调查研究 | 围绕判断了解现状、历史和相互关系 | 访谈数量不能代替样本相关性与证据质量 | S03、S07 |
| 10. 典型调查／解剖麻雀 | 深入具体样本，发现机制，再检验可推广范围 | 代表性须论证；“解剖麻雀”在本索引未作逐字出处认证 | S03、S10 的相关方法 |
| 11. 持久战 | 根据双方特点与变化条件安排长期战略 | 三阶段有特定背景，不是普遍人生周期 | S05 |
| 12. 歼灭战／集中力量 | 在军事语境中集中兵力实现明确战果 | 学习中的掌握标准是类比；不否定渐进和间隔学习 | S04、S12 |
| 13. 根据地 | 支撑持续作战、保存与发展的战略基地 | 生活中的基础条件需要实际存在，未获资格不能算稳固基础 | S19 |
| 14. 纸老虎／战略与战术 | 总体信心与具体问题上的认真准备相结合 | 信心不替代现实风险评估；1957 年完整表述见 S22 | S22 |
| 15. 有理有利有节 | 原统一战线语境中的自卫、胜利与休战原则 | 生活中是边界与成本判断，不能照搬军事手段 | S06 |
| 16. 十六字诀 | 根据敌我行动和条件调整游击战术 | 非一般人际交往规则；转用于竞争要说明类比边界 | S18 |
| 17. 自力更生 | 立足自身组织起来的力量，同时争取外援 | 自主不等于孤立，也不排斥求助 | S21 |
| 18. 星星之火可以燎原 | 从具体社会条件判断小力量发展的可能与趋势 | 不保证任意小积累都会成功或产生复利 | S18 |
| 19. 群众路线 | 汇集实际经验、研究形成意见，再回到实践中检验 | 不是简单多数表决，也不是只找人支持已有答案 | S10 |
| 20. 弹钢琴 | 围绕中心任务协调其他任务与节奏 | 不平均用力，也不要求保留所有战线 | S14 |
| 21. 批评与自我批评 | 检查认识、工作及其错误，促进改进 | 复盘不等于自责；需要证据与改进条件 | S20、S17 |
| 22. 团结—批评—团结 | 在共同目标基础上，经讨论解决问题，形成新的合作 | 不强迫和解，适用前提是仍有共同基础 | S17 |
| 23. 放下包袱开动机器 | 识别错误、成绩、身份等带来的思想负担，恢复判断 | 不能命令情绪消失，也不能抹掉责任 | S20 |
| 24. 愚公移山 | 持续奋斗与动员共同参与相结合 | 生活应用应同时检查方向、代价、支持和反馈 | S11 |

## 常见追问

**主要矛盾和主要方面有什么区别？** 先在多组关系中判断哪一组影响全局，再在选定的一组内部判断哪方面主导。两次判断位于不同层次。证据不足时可以先列候选解释。

**什么都能叫矛盾吗？** 不能只把两件互不相关的事拼成一对。说明同一对象、双方关系、相互依存和制约的机制，才能让这个概念对分析有用。

**“抓主要矛盾”是不是其他事都不要做？** 还需要检验依赖关系与最低维持线；主次不意味着其他问题自动消失。

**三大作风是什么？** 常用概括为理论联系实际、密切联系群众、批评与自我批评。若用户需要逐字原句及版本，另查《论联合政府》原文；本词典不把该概括当成已核验的直接引语。
