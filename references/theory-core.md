# 核心理论与使用边界

下文是方法提炼与生活应用，不是原文逐句翻译。S 编号对应 [原文索引](sources.md)；逐字短引以 [sources.json](sources.json) 为准。

## 1. 实事求是与调查：材料、关系、历史

依据：《反对本本主义》S03、《改造我们的学习》S08、《〈农村调查〉的序言和跋》S07。

调查要服务于一个需要作出的判断。既看现状，也查形成过程；既接触真实经历，也检查数据、规则和不同立场。材料相互矛盾时保留分歧，判断哪种核查能消除关键不确定性。

可以采用四栏：用户陈述／可查材料／暂定推断／尚缺信息。例如“我总是拖延”是用户体验；“最近五次都在任务定义不清时停下”才开始支持一种解释。体验不应被否定，解释仍需检验。

调查质量不由人数或材料条数单独决定。访问几个相关的人是可用办法，但应说明样本是否偏向成功者、条件是否相似、是否遗漏反例。
先问会改变选择的问题；在已有事实足够支持低成本动作时，不用为了“确认完毕”拖延行动。

## 2. 矛盾分析：关系、层次、主次

依据：《矛盾论》S01，重点读第三至六节。

- **矛盾**：同一过程中的双方既相互依存又相互制约。生活分析应说清对象与作用机制，不能只把两个任意词语配成一对。
- **主要矛盾**：在给定过程和阶段中，对其他矛盾的存在与发展起规定或影响作用的一组关系。判断依据是其影响结构，不能只看哪件事最令人焦虑。
- **主要方面**：同一矛盾内部当前占主导的方面，事物的性质主要受它规定。判断其地位和转化需要具体条件；不是再列一个“最重要的问题”，也不等于单方面指责谁有错。
- **特殊性**：不同任务的积累方式、反馈周期、失败成本不同；同一方案对不同人也需要重新检验。
- **同一性与转化**：双方的依存和地位转化有条件。不能只说“坏事变好事”，要说什么行动和环境变化能够促成转化。
- **对抗性**：对抗是解决某些矛盾的形式之一。冲突不自动意味着零和，不同性质的矛盾需要不同办法。

应用示例：讨论一个学期内的安排时，可以先比较“多条路径的投入要求—有限可用精力”“目标不清—承诺过多”“家庭现金需求—全日制备考”三种解释。选择哪一个，取决于实际证据；不能看见多任务就预设必须砍掉实习。

紧急任务可能只是暂时必须处理的事项。先回复一个即将过期的 offer，并不证明 offer 就是整个职业发展的主要矛盾。

## 3. 内因外因：先定分析对象

依据：S01 第一节；组织层面的实例见《解决“五多”问题》S15。

在原论述中，事物的内部矛盾被看作发展的根据，外部条件通过内部结构发生作用。应用时要说出具体机制，不能凭“内因”二字推导谁该负责。

研究个人学习方法时，训练方式属于分析对象内部；研究一个团队的工作负担时，分工、激励和任务下达制度也属于内部结构。内外之分随对象改变，不等于“我的问题／别人的问题”。

另列“可直接改变／可协商影响／暂时需要适应”的行动范围。可控性用于选择行动，因果分析用于理解问题，两者不要混为一谈。
例如，一位员工被多个负责人重复派活，可能需要统一优先级和减少任务来源；仅劝他集中精力，会漏掉制度原因。

## 4. 实践与认识：两次飞跃和可修正性

依据：《实践论》S02。

经历和感觉是认识的材料；经过比较、排除错误信息、分析内部联系，才能形成解释。解释还需要回到实践中接受检验。已有可靠经验也可以借鉴，不必把所有风险亲自尝试一遍。

把行动写成一个可观察的试验：
“当前推测是什么 → 如果成立应看见什么 → 做什么能检验 → 何时判断 → 什么结果要求修改”。
指标可以是任务质量、反馈、资源消耗或关系变化，不能只有忙碌时长。

成功可能受到偶然条件帮助；失败可能来自执行条件或时间不足。复盘要比较竞争性解释，修正判断所依据的材料及其适用范围。需要更长反馈周期的目标，可以先检查过程信号，不能把短期无结果直接认定为方向错误。

## 5. 全局、阶段与战略

依据：《中国革命战争的战略问题》S04、《论持久战》S05。

先看全局目标、资源、时间窗口、依赖关系，再评价一个局部动作。局部胜利如果耗尽下一阶段必需的资源，可能损害整体目标；暂时退让也可能保留后续选择。

阶段判断来自具体条件及其变化。持久战三阶段是对特定战争条件的推演，不是所有长期目标的自然历程。
生活中使用这种类比，要能指出当前差距、可积累的优势、可承受的消耗、转变的条件；不具备时，直接按探索、验证、交付等实际过程分析。

同时说明继续、改变节奏或退出的条件。长期目标中可以有短期集中突破；积极行动也需要休整和资源补充。

## 6. 共同利益、合作与表达

依据：《关于领导方法的若干问题》S10、《关于正确处理人民内部矛盾的问题》S17、《论十大关系》S16、《反对党八股》S09。

涉及他人时，了解对方的真实约束、共同目标、分歧所在和可以检验的事实。意见分歧可通过讨论和试行解决；持续越界则需要明确规则、证据和退出或求助选项。不要先给人贴敌友标签再搜集理由。

一般方法应从具体经验形成，再回到新的具体条件中检验。理论引用用于解释为何这样判断；生活建议的有效性仍要靠事实和反馈支持。表达围绕用户要解决的问题展开，既避免空泛提纲，也避免为显得深刻而堆砌文字。
