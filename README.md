# mao-thought-practice

**用毛泽东思想的方法论分析现实问题的 AI skill。**

把矛盾论、实践论、调查研究、战略策略这些经过实践检验的思想方法,转化为一套可执行的**六步分析工作流**。装上它之后,当你带着现实问题(选择纠结、焦虑、多线作战、人际冲突、坚持不下去……)来问 AI,它会用这套方法帮你理清:

> 摆事实 → 析矛盾 → 判阶段 → 选策略 → 化行动 → 设复盘

> An AI skill that applies Maoist dialectics and methodology to real-life problems and decisions.

## 效果示例

用户问:**"三线作战(保研+考研+实习)焦虑到失眠,帮我分析一下。"**

skill 激活后,输出的结构:

1. **事实梳理**(3-5 条,先确认——"没有调查,没有发言权")
2. **主要矛盾**(一句话说清)
3. **阶段判断**(劣势期 / 相持期 / 转折期,不同阶段策略相反)
4. **策略选择**(从 13 条策略工具中选 1-2 条,说明理由)
5. **行动清单**(2-3 条,具体、可执行、带时间)
6. **复盘约定**(检查点时间 + 复盘问题)

完整示范见 [references/case-studies.md](references/case-studies.md)。

## 安装

### Hermes Agent 用户

```bash
git clone https://github.com/tenderzzz/mao-thought-practice.git ~/.hermes/skills/mao-thought-practice
```

新开一个会话即可生效。

### 其他 AI 工具

- 把 `SKILL.md` 的内容作为系统提示词或知识库文件喂给 LLM;
- 或手动触发:"读一下这份方法论,然后用它分析我的问题。"

## 使用(触发表达)

- **明确点名**:"用**矛盾论** / **毛选思路** / **《论持久战》** 帮我分析一下……"
- **半自动**:当你抛出显著的人生/决策困扰并寻求分析时,AI 可主动提议用这套框架。

推荐提问格式(信息越全,分析越准):

```
用毛选思路帮我分析一下:
现状:……(我是谁、现在什么情况)
目标:……(想要什么、期限)
约束:……(时间/钱/能力/家庭等)
已试过:……(做过什么、结果如何)
纠结的点:……
```

## 设计原则

- **实事求是**:结论从你的具体情况推出,不套模板
- **不喊口号**:输出的是分析,不是宣传;原文引用 ≤2 句/次,且标注出处
- **可执行**:每次分析必须落到"带时间的动作"和"复盘约定"
